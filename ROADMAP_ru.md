# JazzNote — Roadmap

Текущий статус: MVP готов и пригоден для использования — CRUD заметок, live-preview в стиле Obsidian, автосохранение, темы, поиск/фильтры, undo/redo для каждой заметки.

Обозначения: `[x] сделано · [ ] в работе · [~] отложено`

## Следующие задачи

### Удобство
- [x] **Английский UI (i18n)** — словарь и хелпер `t()` подключены по всему UI; переключатель языка в настройках (Русский / English), выбор сохраняется.
- [x] **Своя папка-хранилище** — выбор любой папки под заметки через системный диалог (Настройки → Папка с заметками) с сохранением настройки.
- [x] **Папки** — переименование и удаление папок (удаление непустых работает), создание новых заметок в выбранной папке.
- [x] **Вложенные папки** — папки вкладываются на любую глубину; папку можно переместить в другую папку или в корень через ПКМ-меню.
- [x] **Контекстное меню заметки** — ПКМ по заметке: переименовать, изменить дату, изменить цвет, удалить.
- [x] **Обратный отсчёт до следующего срока** — плашка вверху главного экрана, тикает в реальном времени; скрывается через × или тумблер в настройках, выбор запоминается.
- [ ] **Vim-style горячие клавиши** — навигация с клавиатуры без мыши: `j`/`k` для перемещения между заметками, `h`/`l` для сворачивания/разворачивания папок, `gg`/`G` для перехода к первой/последней заметке, `/` для фокуса на поиск.

### Корректность и чистка
- [x] **Языки подсветки кода** — добавлены CodeMirror-пакеты языков Java, C/C++, PHP, SQL, XML; подсветка работает.
- [x] **Надёжный парсер frontmatter** — экранированные значения в кавычках, `---` внутри текста больше не ломает разбор, скалярные значения без кавычек, ISO-даты.
- [x] **Чистка мёртвого кода** — удалены неиспользуемые IPC-хендлеры (`notes:readDir`, `notes:writeFileSync`, `shell:openPath`) и `theme/codemirror.ts`; `notes:deleteDir` теперь использует `fs.rm` для непустых папок.
- [x] **Эффективность watcher'а** — перезагрузка по событиям файлового watcher'а дебаунсится, серия событий даёт один скан; собственные сохранения игнорируются.

### Напоминалки и уведомления
- [ ] **Напоминалки/будильники для заметок** — заметки уже несут дату `due`; показывать их как системные уведомления и интегрироваться с ОС (Task Scheduler на Windows, календарь/будильник на Android и т.д.).

### Инженерия
- [x] **Тесты + CI** — unit-тесты парсера frontmatter, i18n, color, debounce и шрифтов (Vitest); GitHub Actions workflow запускает тесты и сборку на каждый push/PR.
- [x] **Упаковка и бета-релизы** — Linux (AppImage/deb/pacman) + Windows (NSIS); GitHub Actions по тегу `v*` собирает и публикует релизы с готовыми бинарниками для скачивания.

### Синхронизация и версии
- [x] **Git-хранилище** — папка с заметками инициализируется как git-репозиторий; каждое автосохранение (дебаунс 400 мс) и смена настроек пишут коммит.
- [x] **История версий заметки** — диалог в редакторе со списком версий (hash, дата, сообщение), предпросмотром и восстановлением через новый коммит.
- [x] **Undo/redo до первой версии** — стек отмены засеивается из git-истории (до 500 версий) при открытии заметки.
- [x] **Движок синхронизации** — push/pull/merge против git-remote (URL, логин и токен настраиваются в настройках); неконфликтные изменения мержатся автоматически. Работает с любым доступным remote, который пользователь хостит сам (например, репозиторий на GitHub).
- [x] **Системный git не нужен** — все git-операции выполняются встроенным JS-движком (isomorphic-git) внутри приложения; работает на любом устройстве без установки git.
- [x] **Индикатор синхронизации** — зелёный/жёлтый/красный/оранжевый в правом верхнем углу с подробностями по клику.
- [x] **Разрешение конфликтов** — выбор локальной или серверной версии для каждого конфликтующего файла с предпросмотром.
- [x] **Подключение устройств** — URL, логин и токен remote шарится как QR-код или копируемая строка; импорт сканированием или вставкой на другом устройстве.
- [ ] **Хостинг хранилища на сервере (git smart HTTP)** — веб-сервер **пока не** отдаёт хранилище как git-remote по HTTPS, а серверное хранилище не автосинкается. Это недостающий кусок для готовой к работе синхронизации между устройствами. См. issue #8.

### Веб-версия
- [x] **Веб-версия** — тот же интерфейс работает в браузере (`web/`): маленький Node.js-сервер переиспользует git- и save-логику приложения против того же хранилища.
- [x] **HTTP-приём заметок** — `POST /api/note` создаёт заметки из JSON по токену (`X-Auth-Token` / `JAZZ_NOTE_TOKEN`); удобно с телефона или curl.

## Потом
